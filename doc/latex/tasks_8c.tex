This task guides the user through selecting the Transmit (TX) and Receive (RX) pins for UART communication via a touch-\/based interface on the ILI9488 display. It begins by initializing GPIO pins and prompting the user to select the TX pin.

Once a TX pin is chosen, the display clears and prompts for the RX pin. After both TX and RX pins are selected, a {\ttfamily \doxylink{struct_confirm__struct}{Confirm\+\_\+struct}} is populated with the chosen pins and the task transitions to the {\ttfamily confirm} task to finalize the UART setup or to return to the previous menu. The task continuously monitors for touch input and ensures the watchdog timer is reset to prevent system resets due to inactivity.

It then reads the list of filenames from {\ttfamily /spiffs/notebook/filenames.txt}. If content is found\+:

\item Frees all the {\ttfamily filenames} memory allocated earlier.
\item Creates and transitions to the {\ttfamily notebook\+\_\+edit\+Files\+Page2\+\_\+task}, passing the selected filename as a parameter.
\item Sets {\ttfamily x\+\_\+level} to 1 (likely a flag to prevent re-\/entering this condition).
\item Deletes itself.
\item {\bfseries{"{}close"{} button ({\ttfamily x\+\_\+level} is 0)\+:}} This condition is likely intended for exiting the current page.
\item Clears the screen and the {\ttfamily history\+\_\+char} buffer.
\item Frees the {\ttfamily content} buffer and all {\ttfamily filenames} memory.
\item Creates and transitions to the {\ttfamily note\+\_\+book\+\_\+app\+\_\+page1} task.

\item {\bfseries{"{}close"{} button (another {\ttfamily x\+\_\+level} condition)\+:}} This block appears to handle returning to the file list from a sub-\/menu or a soft-\/reset of the page.

The task runs in an infinite loop, continuously performing the following actions\+:
\begin{DoxyItemize}

\item {\bfseries{Game Mode Selection\+:}} Based on the detected button, it performs the following actions\+:
\item {\bfseries{"{}close"{} button\+:}} Clears the screen, deactivates the display SS line, and creates the {\ttfamily main\+\_\+menu\+\_\+task} before deleting itself.
\item {\bfseries{"{}\+AI vs AI"{} button\+:}} Clears the screen, deactivates the display SS line, and creates the {\ttfamily pong\+\_\+game\+Av\+A\+\_\+task} before deleting itself.
\item {\bfseries{"{}\+Player vs AI"{} button\+:}} Clears the screen, deactivates the display SS line, and creates the {\ttfamily pong\+\_\+game\+Pv\+A\+\_\+task} before deleting itself.
\item {\bfseries{"{}\+Pv\+P"{} (Player vs Player) button (default else case)\+:}} Clears the screen, deactivates the display SS line, and creates the {\ttfamily pong\+\_\+game\+Pv\+P\+\_\+task} before deleting itself.
\item {\bfseries{Display Update\+:}} After processing a touch or in each loop iteration, it ensures the display command is sent and the display SS line is activated.
\end{DoxyItemize}

This task effectively serves as a menu handler, transitioning to different Pong game modes based on user input.
