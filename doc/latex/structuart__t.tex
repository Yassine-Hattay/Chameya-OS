\doxysubsection{Detailed Description}
Represents a UART (Universal Asynchronous Receiver-\/\+Transmitter) configuration. 

This structure holds all the necessary parameters to configure and manage a UART peripheral, whether it\textquotesingle{}s a hardware UART or a bit-\/banged software implementation.
