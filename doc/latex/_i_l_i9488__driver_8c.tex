For each byte in the input array, maps it to two bytes in the output according to predefined rules\+:
\begin{DoxyItemize}

\item 0x\+FF maps to 0x\+FF, 0x\+FF
\item 0x\+F8 maps to 0x\+FF, 0x00
\item 0x07 maps to 0x00, 0x\+FF
\end{DoxyItemize}
