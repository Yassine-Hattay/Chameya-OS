Initializes GPIO for UART reception and creates the bit-\/banging receive task. 

This function configures the {\ttfamily RX\+\_\+\+PIN} as an input with pull-\/up and sets up a negative edge interrupt. It then installs the GPIO ISR service and registers {\ttfamily uart\+\_\+rx\+\_\+isr\+\_\+handler} to detect start bits. Finally, it creates and starts the {\ttfamily uart\+\_\+bitbang\+\_\+receive\+\_\+task} to handle the actual data reception.

Free\+RTOS task for bit-\/banging UART receive. 

This task continuously monitors the {\ttfamily RX\+\_\+\+PIN} for a start bit. Upon detection, it samples the incoming data line at precise intervals to reconstruct bytes. It then stores these bytes in a buffer and, when the buffer is full or a stop condition is met, prints the received string. The task manages enabling/disabling the RX interrupt during reception.
